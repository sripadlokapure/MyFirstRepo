## Task Pilot

`task-pilot/` holds a phone-installable to-do app. Its tasks have activities, statuses and due dates, and a Claude assistant carries out approved tasks. See [task-pilot/README.md](task-pilot/README.md), and [task-pilot/INSTALL.md](task-pilot/INSTALL.md) to install it on your Windows PC or Mac.
